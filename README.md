# Calc Bolos - Sistema de Gestão e Cálculo de Insumos

<p align="center">
  <b>Aplicação desktop desenvolvida para auxiliar na gestão de receitas e no cálculo preciso de custos e proporções de insumos para a fabricação de bolos.</b>
</p>

---

## 🚀 Sobre o Projeto

O **Calc Bolos** é uma ferramenta prática voltada para o ambiente de produção de confeitarias e panificadoras. O sistema automatiza o cálculo de proporções de ingredientes, permitindo adaptar receitas com facilidade para diferentes capacidades de batedeiras industriais e escalas de produção, otimizando o controle de insumos e evitando desperdícios.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java
* **Interface Gráfica:** Java Swing
* **Ambiente de Desenvolvimento:** NetBeans IDE
* **Controle de Versão:** Git & GitHub

## 📋 Principais Funcionalidades

* **Cálculo Proporcional de Insumos:** Ajuste automático de quantidades de ingredientes com base na capacidade da batedeira ou no volume de produção desejado.
* **Otimização de Produção:** Auxílio prático no planejamento diário para produção em larga escala de massas e recheios.
* **Interface Intuitiva:** Tela desktop desenvolvida em Java Swing para agilizar o preenchimento e a visualização dos resultados em tempo real.
